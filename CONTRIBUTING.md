Terima kasih sudah tertarik untuk berkontribusi! Panduan ini akan membantu Anda memulai.

## 📋 Code of Conduct

Proyek ini menganut Code of Conduct yang ramah dan inklusif. Harap hormati semua kontributor.

---

## 🚀 Cara Berkontribusi

### Bug Reports
Jika menemukan bug, silakan buka issue dengan:
- Deskripsi jelas tentang bug
- Steps untuk reproduce
- Expected vs actual behavior
- Browser/device yang digunakan

### Feature Requests
Untuk feature baru:
- Jelaskan use case
- Berikan contoh atau mockup jika ada
- Diskusikan impact ke code

### Pull Requests
1. Fork repository
2. Create branch: `git checkout -b feature/nama-fitur`
3. Make changes & test
4. Commit: `git commit -m 'Add fitur X'`
5. Push: `git push origin feature/nama-fitur`
6. Open PR dengan deskripsi lengkap

## 📝 Code Standards

- Gunakan const/let (no var)
- Konsistensi indentation (2 spaces)
- Comment kode yang kompleks
- Test sebelum push

---

## 🧪 Testing

Sebelum PR:
1. Test lokal
2. Test di browser yang berbeda
3. Test mobile responsiveness
4. Test error handling

---

## 📖 Documentation

- Update README jika ada perubahan besar
- Comment kode yang tidak obvious
- Update changelog (kalau ada)
